# TECHTONIC – YOU HAVE BEEN SUMMONED

Website chúc mừng và chào đón các thành viên mới gia nhập Ban Chuyên môn – Câu lạc bộ TECHTONIC.

## About the Project

Một trải nghiệm chào mừng thành viên mới được thiết kế theo phong cách Cyberpunk / Futuristic Interface, kết hợp các hiệu ứng tương tác, giao diện terminal và hệ thống Member Pass.

### Features

- Futuristic Cyber UI.
- Interactive Terminal.
- Member Pass.
- Welcome & Congratulations Experience.
- Easter Egg – Konami Code.
- BUG HUNTER – Mini Arcade Game.
- Responsive interface for PC and mobile devices.

## Technologies

- HTML5
- CSS3
- JavaScript
- Canvas API

## Deployment

Website được triển khai trực tiếp trên [Vercel](https://vercel.com/) dưới dạng Static Website.

Không yêu cầu cài đặt dependencies hoặc chạy build command.

## How to Run Locally

1. Clone repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Mở file `index.html` bằng trình duyệt.
